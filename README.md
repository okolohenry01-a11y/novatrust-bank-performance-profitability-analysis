# Novatrust-bank-performance-profitability-analysis
SQL Server & Power BI business analysis project exploring bank performance, profitability, customer segments, product adoption, revenue trends, and fee waiver impact.

A comprehensive business analysis and data analytics project for NovaTrust Bank, a fast-growing Nigerian commercial bank. This project uses SQL Server and Power BI to investigate branch performance, customer profitability, product adoption, regional revenue contribution, monthly revenue trends, and the financial impact of fee waivers. The analysis covers one full year of transaction data (January–December 2024), including approximately 2,940 cleaned transactions, 650 customers, 20 branches, and 10 banking products. The project includes data cleaning and validation, SQL Server database and schema design, duplicate removal, data standardization, business-question analysis, star schema data modeling, DAX measures, time-intelligence calculations, KPI development, interactive Power BI dashboard design, insight generation, and data-driven business recommendations. The objective is to transform raw banking transaction data into meaningful insights that can support better decisions around branch performance, customer segmentation, product strategy, revenue growth, and profitability management.
